## Fourth Plan Review Round (same day)

- Fourth review: two blockers + one experimental-design issue (rev-4 findings otherwise resolved).
  Live trickle draws from Godot's global `randf`/`randi`, so the Builder seed alone could not reproduce
  trickle sequences; the sandbox protected only the first Track B run of each model and its
  delete-at-launch rule couldn't represent a controlled second-run profile; single Track A runs per
  cell were vulnerable to composition noise across the models' different RNG streams.
- Rev 5 resolutions (implementation-detail level, no new user forks): **debug-only global seed** —
  the Builder seed field sets `RunState.debug_global_seed`, and only when nonzero does a single call
  site seed the global RNG at room start (normal runs never set it; live trickle untouched); the
  Builder resolves archetypes through the normal generation path (no empty-archetype node); the
  sandbox gains **`fresh`/`keep` modes** and Track B pairs every run via an immutable post-run-1
  snapshot (S1) copied into place before `keep` launches; Track A adds **two paired seed repetitions
  per cell** plus spawn-composition logging with a 10% totals band — cells outside the band are marked
  quantity-confounded, and A1 (open, uncapped) is the primary evidence config.
