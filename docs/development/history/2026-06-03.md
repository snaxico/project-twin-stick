## What Changed

- Removed level-up VFX and its runtime listener.
- Tuned baseline and abilities:
  - starter `Rifle` fire rate is now `5.0`
  - `Overcharge` is now `1.5x` fire-rate plus `2x` projectiles
  - `Blink` now uses movement direction, `340px` range, short arrival i-frames, and arrival detonation
  - `Turret` and `Minefield` were buffed
  - mines now separate trigger radius from explosion radius
- Reworked Fire Trail:
  - longer / faster ticking path zones
  - larger usable path-zone radius
  - one larger impact pool on hit / expiry
  - new impact-pool params compile through `MutationSystem.gd`
- Increased Fire Floor pressure:
  - radius `280`
  - max active zones `7`
  - faster spawn interval
  - margin adjusted so larger zones stay inside the arena
- Reworked HUD / pause clarity:
  - dedicated side-objective panel with label, progress text, and progress bar
  - Kill Streak is now a true fixed-target streak and resets on actual player damage
  - pause `Settings` now opens the existing in-run panel
  - in-run settings control screen effects and per-player aim mode
- Reworked elite / boss pressure:
  - elites spawn away from player center spawn positions
  - Elite Charger has a stronger telegraphed charge and slam
  - Elite Spitter uses a wider led projectile fan
  - Elite Support adds a damaging pulse to its minion pressure
  - bosses have higher threat, HP-threshold phase telegraphs, add pressure, and heavy-attack tells
- Added performance cheap wins:
  - player and enemy projectiles now use a reusable pool
  - enemy target acquisition is staggered across physics frames
  - inactive pooled projectiles are ignored by shockwave / VFX load checks
- Removed dead `_estimate_room_total_enemies()` after Kill Streak switched to fixed target.

## Round-5 What Changed

- Removed the in-run pause Settings panel:
  - main-menu Settings / input rebinding remains intact
  - pause menu now shows Resume / Restart Room / Main Menu plus build summary
  - aim mode support remains in code but current runtime defaults to auto-target
- Reworked Fire Trail into `Fire Bullets`:
  - no along-flight fire zones
  - projectiles create one smaller burning impact pool on hit / expiry
  - params are `50px`, `2.0s`, `0.4` damage percent
- Nerfed `Overcharge`:
  - cooldown `22s`
  - duration `4s`
  - `1.3x` fire-rate
  - no extra projectiles
- Added additive ability lockout support:
  - `Player.apply_ability_lockout(seconds)`
  - `Dash.extend_cooldown(seconds, now)`
  - Pulsar EMP delays Dash and non-Dash ability cooldowns
- Increased boss HP to round-5 values:
  - Warden `1650`
  - Hydra `2100`
  - Hive `1800`
  - Pulsar `1950`
- Reworked bosses:
  - Warden: leap, multi-charge, ground-pound shockwave, speed ramp
  - Hydra: aimed snipes, rotating sweep, phase minions, slow homing orbs
  - Hive: shield minions, poison cloud, burrow relocate, escalating minion mix
  - Pulsar: teleport, EMP, sweeping beam, stronger phase-3 pressure
- Added review safeguard after implementation:
  - Hive shield count fixed at `4`
  - Hive phase transitions only spawn a new shield if the old shield has already been cleared
- Reworked elites:
  - Act 2 elites get `1.5x` HP, `1.3x` damage, and `25%` faster elite cooldowns
  - elite rooms spawn 2-3 regular adds every `6-8s` while the elite is alive
