Implemented the approved choices/builds replayability patch on `v3/structure-rework`.

  chance.

  backstop.

- Existing weapon rares now seed tags: Fire, Frost, Toxic, and Split.

  Glass Cannon, Cryo Shatter, and Virulent.

- Signature transformers now compile into projectile/beam behavior flags for split chaining, ignite-on-death,
  shatter-on-death, and max-momentum pierce.
- Parasites are marked and kept declinable by replacing an all-parasite offer when a non-parasite is
  available.
- UI rarity handling now treats Signature as above rare for reward cards, build chips, and loadout summary.

### Phase B - meta score and unlocks

- `ProfileState` now persists `banked_score` and `unlocked_ids`, with a shared unlock table and reset.
- `RunState` owns run score and banks it once at terminal run end.
- `CoopManager` writes room score on clear or wipe using:
  `clear_credit + kills + champion_kills*250 + room_max_momentum_tier*50`.
- The HUD and route screen show current run score; death resolution shows earned score and new banked total.
- Existing Meta buttons/panel are now wired into a scrollable unlock menu.
- Starting profiles are lean: Rifle, Shotgun, Overcharge, Dash, and base common upgrades are free; locked
  weapons, abilities, rares, and Signatures enter setup/roll pools only after purchase.

## Playtest fixes (round 1)

First playtest of the patch. Findings + fixes:
- **Hive champion was invincible.** `apply_damage` blocks all damage while champion deflectors are up
  (`Enemy.gd`), and `_update_hive_behavior` respawned 4 deflectors the instant they were empty — the old
  phase-gated respawn was dropped in the champion conversion, so deflectors came back every frame →
  permanent invincibility. Fixed: deflectors now open a **`HIVE_DEFLECTOR_VULNERABLE_WINDOW` (6s)** after
  being cleared before the next set can spawn (tracked via `_champion_deflectors_present` /
  `_next_champion_deflector_at`), giving a real damage window.
- **Starting-weapon summary showed "Scattergun".** `_sync_weapon_row_buttons` formatted the weapon *id*
  (`_format_name("scattergun")`) instead of the display name. Now reuses the selected card's label →
  "Shotgun".
- **Encyclopedia:** added a **Systems** category with **Score** (formula + banking rules) and
  **Momentum / Flow** (tiers, bonuses, −2 on hit, persists per run) entries.
- **UI feedback (positive):** user likes the new next-room card style; noted as the template for future
  UI improvements (memory).
- Verified the earlier `Momentum Surge` review fix is in: fire-time `pierce_at_max_momentum` flag applied
  from live momentum tier in `Player`.

## QoL & difficulty patch implemented

Implemented the approved QoL/difficulty patch after replayability playtest feedback.

- Reward picks now include navigable `Reroll` and `Skip` slots using the existing left/right/confirm input.
- Rerolls spend shared unbanked `RunState.run_score` with a per-pick escalating cost and update both players'
  shared score display.
- Rerolls regenerate offers without touching `rare_dry_streak`; Champion Reward rerolls keep the round-level
  forced rare, while dry-streak pity only applies to the initial offer.
- Skip resolves that player's pick with no upgrade and still consumes the pick round when all players resolve.
- Early-game pressure was raised with stronger chasers/chargers, a tighter early spawn interval, and larger
  opening/periodic bursts.
- HP drops were reduced from 10% to 6%, and pickups now heal 8 instead of 10.
- Kill-streak side objective target increased from 18 to 30.
- Encyclopedia rows and details now show visual previews: enemies use the live enemy visual profile, weapons
  use the base projectile-kind visual mapping, abilities/mutations reuse `IconFactory`, and modifiers use
  compact versions of their in-game hazard visuals.

## Game feel & neon identity patch implemented

Implemented the approved pure in-engine presentation patch on `v3/structure-rework`.

- Runtime arena rendering now owns the neon identity pass: `_rebuild_floor_grid()` creates metadata-backed
  Line2D grid lines, `_add_arena_wall_visuals()` adds layered glow/core border lines, `_update_grid_pulse()`
  pulses the grid and brightens lines near living players, and the floor base is now dark neon instead of
  prototype beige/black.
- Major hazard rooms keep the existing `ModifierTint` ownership: neutral white by default, then a subtle

  set from gameplay.
