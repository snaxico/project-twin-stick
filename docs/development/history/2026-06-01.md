## Code Review Pass

A full code review of the V3 implementation was run against all roadmap tiers.

### Bugs found and fixed

- **Decoy not targetable by enemies**: `DecoyNode.gd` was missing `add_to_group("player_target")`. Enemies use this group to find targets, so decoys were invisible. Fixed.
- **Endless mode rare chance 20% instead of 30%**: `_get_current_rare_chance()` only checked act, not run mode. Added endless check returning `0.30`.

### Dead code identified

- `GoldPickup.gd`, `HealthPickup.gd`, `GoldPickup.tscn` — deleted (never spawned in V3)
- Gold stub functions in `RunState.gd` remain as no-ops
- `_update_decoys_and_helpers()` in CoopManager was a no-op (loop bodies were empty `continue`)

### Minor deviations noted

- Splitter color is purple (roadmap said green) — cosmetic
- Bomber color is yellow (roadmap said dark red) — cosmetic
- `wave_count` fields in RunState node data are now unused

## Playtesting Fixes

After the code review, manual playtesting revealed four critical issues:

### 1. Spawning changed from waves to continuous time-based

- **Problem**: enemies dumped all at once per wave; next wave waited for all current enemies to die. Felt static and bursty.
- **Fix**: replaced with continuous timer-based spawning. One enemy per interval (1.3-1.8s), room has a fixed duration (35s Act 1, 45s Act 2). Spawning stops when timer expires; room clears when remaining enemies die.
- `Accelerating Waves` modifier now ramps spawn interval from 100% to 33% over the room duration.
- `Swarm` modifier spawns 2 at a time with half HP.

### 2. Enemy spawn positions outside arena walls

- **Problem**: `_get_enemy_spawn_position()` relied on scene marker nodes (EnemySpawn1-6) that could be placed outside arena boundaries.
- **Fix**: replaced with programmatic edge spawning — picks random arena edge and spawns inside the wall margin with slight random offset.

### 3. Ability selection cards too large

- **Problem**: ability cards had 96px minimum height with expanded icon textures, making the grid unusable especially with 9 abilities.
- **Fix**: reduced to 44px height, removed icons, text-only labels ("Shockwave — AOE blast around the player…").

### 4. Map branch nodes overlapping

- **Problem**: 96×60 buttons with icons crammed horizontally using a fixed 5-column grid mapping, causing overlap on maps with many rows.
- **Fix**: reduced to 72×36, removed icons, font size 11, nodes positioned by actual column rank within their row. Single-line compact labels.
