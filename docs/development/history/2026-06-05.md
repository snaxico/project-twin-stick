## Playtest Round 10 Implementation

Implemented `docs/development/playtest-round-10-plan.md` locally.

### Gameplay / Combat

- Room clear now pauses runtime hazards, enemies, projectiles, mines, and active ability nodes before reward/map UI opens.
- Rare odds changed to `15%` Act 1, `25%` Act 2, and `35%` Endless.
- Added per-player rare pity tracking: after `4` dry pick rounds, that player gets a forced-rare roll; any rare option in that player's offered cards resets the streak.
- `Minefield` is now instant and stacking: `7s` cooldown, `0s` active duration, and `mine_lifetime: 14`.
- `Minefield` duration synergy remains intentional through `mine_lifetime` scaling.
- Scanline modifier now caps at `2` active sweeps, spaces spawns to `8.0-9.5s`, and widens safe gaps to `200-240px`.
- 2P camera tuning now allows closer zoom and uses less padding.
- Hive boss now spawns extra player-position pressure adds while respecting the shared boss add cap.
- Bosses now start with a `2.5s` invulnerable entrance windup and delayed add waves.
- Warden, Hydra, and Pulsar heavy attacks now use delayed tells where the current code path supports scheduled effects.

### UI / Audio / Debug

- Added idempotent `Master` / `Music` / `SFX` audio-bus setup and settings sliders.
- Added procedural adaptive music on the `Music` bus.
- Retuned procedural SFX to be softer and less sharp.
- Reward cards were trimmed by merging rarity/group metadata and moving confirm help to a shared panel hint.
- Setup now supports per-player starting weapon selection.
- Ability selection summary now shows selected OFF/DEF descriptions.
- Route map now presents only current route-choice cards with room type, boss/elite tag, objective, modifiers, enemy pool, and description.
- Encounter Builder is gated behind debug builds or `--debug-menu`.
- Encounter Builder can launch any boss type and includes starting level/XP cheats plus a perf scenario launcher.
- Added `PerfRunner.run_from_menu(profile, players, build)`.
- Added rebindable debug overlay action, default `F4`.
- Added in-room debug overlay for live spawn, clear enemies, god mode, and weapon-level cheat.
