## Structure Rework "Trim" — Design Locked

Debated and locked the next major direction: `docs/development/structure-rework-plan.md`. Design only,
**not implemented.** Supersedes the structural half of `playtest-round-14-plan.md` Part B and
**cancels Patch 3 (boss set-pieces)**.

### Decisions

- **Trim, not a pivot.** Keep the roguelite identity; cut the two heaviest/least-validated structural
  systems.
- **Remove the branching map** → flat between-room **risk/reward choice card** (reuse route-card UI).
- **Remove dedicated boss rooms** → **convert all four boss kits** (Warden/Hydra/Hive/Pulsar) into
  **elite champions** woven into normal waves, each keeping 1–2 signature telegraphed attacks, via the
  repurposed elite add-wave system.
- **Two modes kept, split by boundedness:** Structured = bounded ~10-room / ~15-min run → win screen
  (champions fixed at room 5 + 10); Endless = unbounded → score (champions every 5 rooms). Both also
  allow opt-in champion rooms from the card.
- **Run stake = nothing persists** (HP and momentum still reset per room); the run itself is the stake
  (death ends it). So the choice card pairs a **risk kind** (standard / swarm / major modifier /
  elite-add / champion) with a **reward category** (Weapon/Effect/Attribute/Ability) + a rarity nudge
  that scales with risk; the 2–3 shown options must differ on both axes.
- **Enemy re-tune = last phase**, low-HP / high-threat philosophy; keep current values until then.
- **Onboarding = deferred.**

### Phasing

Strip map → choice card → champions → mode framing → enemy re-tune (last). Each becomes its own
bounded, Codex-ready task with numbers filled in. Champions-in-a-dense-wave is a new PerfRunner case.

### Follow-up refinements (open items walked step by step)

- **Threat ladder = unified champion tier.** Elites and bosses collapse into one "champion" tier above
  trash (two-tier ladder); pool = 7 champions (4 bosses + 3 former elites). No separate elite tier;
  "elite rooms" become "champion rooms" and keep the bonus pick.
- **Champion look = bigger + aura + named health bar** — repurpose the boss HP bar (minus phase pips)
  instead of deleting it.
- **R14 confidence = thorough**; build the rework straight on top, no extra validation pass.
- **Difficulty = steady climb**, Act 2 baseline above Act 1.
- **Modifiers = forced by depth** (ambient), not a choice-card option; the card layers risk + reward on
  top of whatever modifier the room already carries. This thins card risk kinds to
  `standard / swarm / champion` (reward category carries the rest of the differentiation).

## Structure Rework — Big Update: One Continuable Run

Reconsidered the fixed Structured/Endless split (sparked by a Brotato-style "fixed end that continues
into endless" idea). Confirmed the loadout + modifier systems are agnostic to rooms-vs-waves (they hang
off the encounter boundary), but chose to **keep clear-the-room encounters** (not survival-timer waves)
and **add the continue mechanic**. Net change to the plan:

- **One continuable run, no mode split.** Drop the Structured/Endless menu split. A single run = a
  curated arc of `RUN_LENGTH` rooms → **win milestone** (win screen + score, "continue into Endless?")
  → **seamless endless continuation** (same run, difficulty keeps climbing, champions every 5). Menu =
  just **Play**; old "Endless" is the post-milestone continuation.
- **Run length = tunable constant `RUN_LENGTH`** (target ~10), pinned in playtest tuning — not a hard 10.
- **Continuation difficulty keeps climbing seamlessly** (one curve, no reset).
- **Pick cadence stays XP-gated** (unchanged) — long continuation keeps granting picks via levels.
- Phase 1 absorbs this: linear builder must **extend past `RUN_LENGTH`** and the **separate endless
  generation path collapses** into it; remove the mode-selection screen (`Bootstrap.gd`). Phase 4
  becomes the **win-milestone + continue UX**.
- New playtest watch-items: the win milestone must feel like an earned peak (not a speed bump); the
  continuation must not spike unfairly right after the finale champion.

## Structure Rework — Simplify the Between-Room Mechanic

User direction: keep the **existing loot and modifier structures**, and make the between-room mechanic a
plain **pick-one-of-two** instead of the elaborate card economy ("for now"). Scope = "just the card
simplifies" — all other locked rework decisions stay (one continuable run, bosses→champions, win
milestone, unified champion tier, nothing-persists).

### Reverted / simplified

- **Dropped** the risk-kind × reward-category card, rarity nudges, and the custom forced-by-depth
  modifier rule (`_forced_modifiers_for_room`).
- **Modifiers** use the existing `_roll_modifiers_for_node` rolling (already act/depth-scaled); each of
  the 2 options carries its own rolled modifiers, so the modifier is part of the choice.
- **Loot** unchanged — existing reward sequencing + current rare odds; champion rooms keep the existing
  elite-room bonus pick.
- **Phase 1 rewritten** as "strip map → lazy 2-option chooser using existing generation" (`_build_choice_step`):
  2 option nodes per normal step via `_build_map_node` + `_roll_modifiers_for_node` + `_ensure_route_options_differ`;
  beat steps (every 5) return 1 forced boss node. The old separate "choice card" phase folds into Phase 1.
- Phases renumbered: 1 strip-map/2-option · 2 champions · 3 win-milestone+continue · 4 enemy re-tune.
- Richer risk/reward economy + parasite items are **parked, not cancelled** — revisit only if the simple
  2-option choice feels thin in playtest.

pips (keep HP bar), windup, dedicated boss-room flow. Look = bigger + aura + named HP bar (no pips).

approach.
