## CoopManager decomposition started

Started the `CoopManager.gd` decomposition on `v3/structure-rework` with the low-risk phases from
`docs/development/coop-manager-decomposition-plan.md`.

### Phase 0 cleanup

- Removed dead `RunState.run_mode`, `is_easy_mode()`, and `is_run_complete()` leftovers after confirming
  there were no live code callers.
- Added a diagnostic warning for unknown `ProfileState.is_unlocked()` IDs while preserving the existing
  unlocked-by-default return behavior.
- Left optional Hive deflector timer cleanup unimplemented for now because it is behavior-adjacent and not
  required for the structural decomposition.

### Phase 1 stateless helpers

- Added `CoopFormat.gd` for room/boss/modifier/buff formatting, slot colors, overbright color, and rarity
  rank.
- Added `EnemyTypes.gd` for champion enemy ID normalization and champion classification.
- Added `ArenaGeometry.gd` for segment distance, player/enemy/champion spawn-position math, and projectile
  spread directions.
- `CoopManager.gd` still owns runtime orchestration and the combat-owner facade; these extractions do not
  move any stateful gameplay ownership.
