## Round-9 What Changed

- Reworked the old mutation reward model into the live Weapon / Effect / Attribute / Ability upgrade model.
- Added five peer weapons:
  - `Rifle`
  - `Rocket Launcher`
  - `Scattergun`
  - `Cannon`
  - `Railgun`
- Added shared per-player `weapon_level` from `1-5`.
- Added reward cards for:
  - `Level Up Weapon`
  - `Change Weapon -> X`
- Rescaled the number model:
  - player HP is now `100`
  - base weapon damage is lower
  - weapon level is the main offense axis
  - enemy HP/damage and flat ability damage were rescaled around the new model
- Removed old weapon-shape mutations from the live upgrade pool:
  - `Split Shot`
  - `Big Shot`
  - `Pierce`
  - `Explosive Rounds`
- Added/retuned attribute commons:
  - `High Caliber`
  - `Range`
  - additive knockback bonus
  - retuned `Rapid Fire`
- Added ability signature rares:
  - `Shockdash`
  - `Twin Charge`
  - `Aegis Burst`
  - `Volatile Decoy`
  - `Twin Turret`
  - `Expanding Orbit`
  - `Extra Mines`
- Kept existing Overcharge and Shockwave ability rare pilots live.
- Added four group visuals for reward cards:
  - `Weapon`
  - `Effect`
  - `Attribute`
  - `Ability`

## Follow-Up Fixes

- Projectile trail styles now create distinct trails instead of using one generic trail for all weapons/effects.
- Shockdash overlap checks now include enemy collision radius so dash-through hits are not missed.
- Pause build overlay now uses compiled runtime weapon stats when available.
- Mutation reward UI now caches mutation definitions instead of rebuilding lookups repeatedly during refresh.
- Fixed Godot unused-parameter warning in `MutationSystem.get_knockback_multiplier()`.
- Disabled P2 controller gameplay control:
  - P2 setup is keyboard-only
  - run launch forces P2 to keyboard
  - default controller motions are only added for P1
  - stale saved P2 controller bindings are stripped on startup/reset
  - P2 controller binding buttons are disabled in Settings
